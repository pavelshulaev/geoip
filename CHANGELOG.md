# Changelog

История версий модуля «GeoIp Api» (rover.geoip). Составлена по разделу «Что нового» на
[странице модуля в Маркетплейсе Битрикс](https://marketplace.1c-bitrix.ru/solutions/rover.geoip/).

## 2.0.0 — 2026-08-05
- Список geoip-служб теперь строится через событие `onBuildServiceList` модуля `rover.geoip` вместо жёсткого сканирования каталога `lib/service/`.
- Встроенная служба (Sypex) регистрируется тем же событием — можно подключать собственные службы из других модулей без правки ядра модуля (см. README, раздел «Расширение списком служб»).
- `Service::build()` упрощён: принимает только полное имя класса службы (FQCN); поддержка короткого имени убрана.
- Удалены службы IpGeoBase (ipgeobase.ru) и FreeGeoIp (freegeoip.net) — оба сервиса прекратили работу, публичное api недоступно. Вместе с классами удалены неиспользуемые опции `ipgeobase-active` и `freegoip-active`. При необходимости их можно подключить как сторонние службы через `onBuildServiceList`.
- Исправлена рассинхронизация кэша `Location::getInstance()`: `reload($ip)` с явно указанным ip теперь обновляет `$this->ip` и переиндексирует внутренний кэш инстансов, чтобы повторный `getInstance()` по старому ip не возвращал объект с данными уже другого адреса.
- `Location::getData()` при ошибке пишет в поле `error` текст исключения вместо статичной строки `'error'` — упрощает диагностику.
- Все обращения к строкам локализации переведены с устаревшей `GetMessage()` на `\Bitrix\Main\Localization\Loc::getMessage()`.
- Минимальная требуемая версия php повышена до 8.1 — синхронизирована проверка при установке (`install/index.php`) с фактическим рантайм-гейтом модуля (`include.php`). Ранее проверка при установке пропускала php 7.2, хотя модуль уже не грузился на версиях ниже 8.1.
- Компонент `rover:geoip.user.location`: получение IP регистрации пользователя переведено с прямого SQL-запроса к таблице `b_stat_session` на D7 API (`\Bitrix\Statistic\SessionTable`); при отсутствии установленного модуля «Веб-аналитика» метод корректно возвращает `null` вместо запроса к несуществующей таблице.
- Компонент `rover:geoip.user.location`: добавлена проверка прав — просматривать и изменять данные пользователей может только администратор (`$USER->IsAdmin()`); иначе выбрасывается исключение с сообщением о нехватке прав.
